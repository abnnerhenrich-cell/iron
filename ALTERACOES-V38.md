# IRON V38

- Removidos os destaques azuis remanescentes; identidade visual forçada para preto, grafite e prata.
- Campos de data deixaram de depender do seletor nativo do navegador, que podia exibir MM/DD/YYYY.
- Entrada de data agora é explicitamente DD/MM/AAAA, com máscara.
- Backend aceita DD/MM/AAAA e também ISO para compatibilidade.
- Exibição de datas padronizada em DD/MM/AAAA.
