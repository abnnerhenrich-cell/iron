# IRON V11 — Meta ativa automaticamente

- Toda meta nova é ativada automaticamente no momento da criação.
- A meta anteriormente ativa é desativada automaticamente.
- Removida a opção “Ativar ao criar”, pois agora o comportamento é padrão.
- O botão de ativar metas antigas foi mantido para permitir reativação manual de uma meta anterior.
