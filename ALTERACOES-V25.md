# IRON V25 — Sistema de saldos refeito

## Conceito simplificado
- “Crédito” foi reorganizado visualmente como SALDO.
- Saldo positivo reduz a próxima meta.
- Saldo negativo aumenta a próxima meta.
- O fechamento é decidido produto por produto.

## Fechar período
Para cada produto o admin vê:
- necessário;
- aprovado;
- diferença;
- decisão: levar a diferença para a próxima meta ou concluir zerando.

## Central de saldo
- Um único lugar mostra os saldos atuais.
- É possível editar o valor manualmente.
- É possível zerar o saldo.
- Ao criar a próxima meta do mesmo produto, o saldo continua sendo aplicado automaticamente.

## Histórico
- O extrato agora mostra todos os fechamentos, inclusive os já aplicados.
- Estados: PENDENTE, APLICADO e SEM SALDO.
- Fechamentos ainda não consumidos podem ser reabertos.
- Entregas e aprovações permanecem abaixo do extrato.

## Compatibilidade
- Mantidas as tabelas e dados das versões anteriores.
- Não exige apagar o banco.
