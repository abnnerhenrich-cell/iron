# IRON V15 — Correção da Placa Blindada

- A quantidade de Colete não soma mais automaticamente na Placa Blindada.
- Placa Blindada agora usa somente o valor informado no próprio campo.
- Ao deixar Placa Blindada em 0, todos os materiais dela voltam imediatamente para 0.
- Removido o texto que dizia que cada colete incluía automaticamente uma placa.
- Atualizado o versionamento dos arquivos da calculadora para evitar JavaScript antigo em cache.
